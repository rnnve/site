## Special Custom Tags

These are custom components available in all MDX files.

### `<Rainbow>`

Animated rainbow gradient text.

<Rainbow>This text has a rainbow gradient animation</Rainbow>

**Usage:**
```mdx
<Rainbow>Your text here</Rainbow>
```

### `<Neutral>`

Animated neutral (grayscale) gradient text.

<Neutral>This text has a neutral gradient animation</Neutral>

**Usage:**
```mdx
<Neutral>Your text here</Neutral>
```

### `<Pink>`

Pink colored text.

<Pink>This text is pink</Pink>

**Usage:**
```mdx
<Pink>Your text here</Pink>
```

### `<Underline>`

Underlined text with custom styling.

<Underline>This text is underlined</Underline>

**Usage:**

### `<Time>`

Displays the current time. Updates every second.

**Visitor's local time (auto-detected timezone):**
<Time />

**With seconds:**
<Time showSeconds={true} />

**Specific timezone:**
<Time zone="America/New_York" />

**Specific timezone (Tokyo):**
<Time zone="Asia/Tokyo" />

**Short format:**
<Time format="short" />

**Time only format:**
<Time format="time-only" />

**UTC time:**
<Time zone="UTC" />

> **Note:** The component must be capitalized as `<Time>` because `<time>` (lowercase) is a native HTML element and will not work as a custom component.

**Usage:**
```mdx
{/* Visitor's local time */}
<Time />

{/* With seconds */}
<Time showSeconds={true} />

{/* Specific IANA timezone */}
<Time zone="America/New_York" />
<Time zone="Asia/Tokyo" />
<Time zone="Europe/London" />

{/* Format options */}
<Time format="full" />      {/* Default: "Mon, Jan 15, 2025, 14:30 (PST)" */}
<Time format="short" />     {/* "Jan 15, 14:30 (PST)" */}
<Time format="time-only" /> {/* "14:30 (PST)" */}

{/* With seconds enabled */}
<Time format="full" showSeconds={true} />      {/* "Mon, Jan 15, 2025, 14:30:45 (PST)" */}
<Time format="time-only" showSeconds={true} /> {/* "14:30:45 (PST)" */}

{/* Combined */}
<Time zone="UTC" format="time-only" />
```

**Props:**
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `zone` | string | Auto-detected | IANA timezone (e.g., "America/New_York") |
| `format` | "full" \| "short" \| "time-only" | "full" | Display format |
| `showSeconds` | boolean | false | Show seconds in time |

**Common IANA Timezones:**
- `America/New_York` (EST/EDT)
- `America/Los_Angeles` (PST/PDT)
- `America/Chicago` (CST/CDT)
- `America/Denver` (MST/MDT)
- `Europe/London` (GMT/BST)
- `Europe/Paris` (CET/CEST)
- `Asia/Tokyo` (JST)
- `Asia/Shanghai` (CST)
- `Asia/Dubai` (GST)
- `Australia/Sydney` (AEST/AEDT)
- `UTC` (Coordinated Universal Time)

### `<HoverTooltip>`

Displays a tooltip/popup on hover with additional information or a link.

```mdx
<HoverTooltip content="This is a tooltip with additional information">
  Hover over this text
</HoverTooltip>

<HoverTooltip content="https://github.com" href="https://github.com">
  Hover for GitHub link
</HoverTooltip>
```

**Live examples:**

**Basic tooltip:**
<HoverTooltip content="This is a tooltip with additional information">Hover over this text</HoverTooltip>

**Tooltip with link (inline):**
Hover me for <HoverTooltip content="https://github.com" href="https://github.com">GitHub</HoverTooltip> link.

**Props:**
| Prop | Type | Required | Description |
|------|------|----------|-------------|
| `content` | string | Yes | Text to display in the tooltip |
| `href` | string | No | Optional URL to make the tooltip a link |

## Combining Elements

You can combine custom tags with regular markdown:

<Rainbow>**Bold rainbow text**</Rainbow>

<Neutral>*Italic neutral text*</Neutral>

<Pink>`Inline code in pink`</Pink>

<Underline>~~Strikethrough with underline~~</Underline>

## Escaping

To display the literal tag names without rendering them, use backticks:

- `` `<Rainbow>` `` renders as: <Rainbow>rainbow text</Rainbow>
- `` ` \`<Rainbow>\` ` `` renders as: `` `<Rainbow>` ``
